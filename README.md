# CSS Color Visualizer

An interactive, beginner-friendly project that explains how **RGB, RGBA, HEX, HEXA, HSL and HSLA** colors work.

Move the sliders, change the values, and immediately see how they affect the color and its transparency.

Built with **HTML, CSS and vanilla JavaScript**. No frameworks, backend or package installation required.

## Concepts Explained

### RGB and RGBA

RGB represents a color using red, green and blue channels.

The demos use channel values from **0 to 255**. Alpha adds control over opacity, from **0** for fully transparent to **1** for fully opaque.

### HEX and HEXA

HEX writes RGB channel values using hexadecimal notation:

- `#RRGGBB` represents red, green and blue.
- `#RRGGBBAA` includes an additional alpha channel.
- Each pair ranges from `00` to `FF`, corresponding to decimal values from 0 to 255.

The HEX demo shows how each pair converts into a decimal value.

### HSL and HSLA

HSL describes a color using:

- **Hue:** the color's position around a color wheel.
- **Saturation:** how colorful or gray the color is within this model.
- **Lightness:** the progression from black through the color to white.
- **Alpha:** an optional value controlling opacity.

### Same Color, Different Formats

RGB, HEX and HSL can represent the same color using different notation or components.

Some displayed conversions are rounded, so converted values may be approximate.

## Run Locally

1. Clone this repository or download and extract its ZIP file.
2. Open `index.html` in your browser.
3. Choose a demo and move the sliders to explore the colors.

You can also open individual demo files directly.

No `npm install` or build command is needed.

> If your browser blocks the Copy buttons when opening files directly, serve the project through a local web server and open it using localhost.
